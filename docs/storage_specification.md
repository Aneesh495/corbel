# Corbel Physical Storage and File Format Specifications

This document defines the binary layout and byte-level schemas for all segment files generated by the Corbel search engine.

All multi-byte numeric values are encoded in Little-Endian byte order unless prefixed by variable-byte (VByte) encoding.

---

## File Extension Summary

| Extension | Subsystem | Format Description |
|-----------|-----------|--------------------|
| `.cbl_fst` | Term Dictionary | Finite State Transducer minimal acyclic automata graph |
| `.cbl_pos` | Postings Lists | Delta-gap doc IDs, frequencies, positions, offsets, skip lists |
| `.cbl_dvs` | Columnar DocValues | GCD-compressed numerics, binary payloads, sorted set ordinals |
| `.cbl_fdx` | Stored Fields Index | Block entry table mapping doc IDs to compressed payload offsets |
| `.cbl_fdt` | Stored Fields Data | Block-compressed JSON document records (64 docs per block) |
| `.cbl_vec` | Vector Index | HNSW multi-layer adjacency lists and float vector buffers |
| `.cbl_del` | Deletion Vector | RoaringBitmap serialization of soft-deleted document IDs |
| `corbel.wal` | Write-Ahead Log | CRC32C-guarded transactional append log for durability |

---

## 1. Term Dictionary (`.cbl_fst`)

Stores the minimal acyclic directed graph representing all indexed terms and their file byte offsets into the `.cbl_pos` postings file.

```
+-----------------------------------------------------------+
| Field Name (VByte length + UTF-8 string)                  |
+-----------------------------------------------------------+
| State Count (VInt)                                        |
+-----------------------------------------------------------+
| State 0: IsFinal (Byte) | FinalOutput (VLong)             |
|          Arc Count (VInt)                                 |
|          Arc 0: Label (Byte) | Output (VLong) | TargetId |
|          Arc 1: Label (Byte) | Output (VLong) | TargetId |
+-----------------------------------------------------------+
| State 1 ... State N                                       |
+-----------------------------------------------------------+
| Sentinel Field Name: "" (0x00)                            |
+-----------------------------------------------------------+
```

---

## 2. Postings Lists (`.cbl_pos`)

Postings streams store inverted document references, occurrence frequencies, token positions, character offsets, and skip-list index blocks.

```
+-----------------------------------------------------------+
| Flags (Byte): [storePositions: 1 bit | storeOffsets: 1 bit]|
+-----------------------------------------------------------+
| Total Document Count in Postings List (VInt)              |
+-----------------------------------------------------------+
| Skip List Entry Count (VInt)                              |
|   Skip Entry 0: DocId (VInt) | ByteOffset (VLong)         |
|   Skip Entry 1 ... Skip Entry S                           |
+-----------------------------------------------------------+
| Posting Block:                                            |
|   Doc ID Delta Gap (VInt): (docId - prevDocId)            |
|   Term Frequency (VInt): occurrences in document          |
|   Positions (if enabled):                                 |
|     Pos Delta Gap 0 (VInt) ... Pos Delta Gap F            |
|   Offsets (if enabled):                                   |
|     Start Offset 0 (VInt) | Length 0 (VInt)               |
+-----------------------------------------------------------+
```

---

## 3. Columnar DocValues (`.cbl_dvs`)

Contains columnar DocValues data streams for rapid filtering, numeric ranges, sorting, and aggregations.

### Numeric DocValues Layout
```
+-----------------------------------------------------------+
| Doc Count (VInt)                                          |
| Min Value (Int64)                                         |
| GCD Multiplier (Int64)                                    |
| Bits Per Value (Byte)                                     |
| Packed Bit Buffer (ceil((DocCount * BitsPerValue) / 8))   |
+-----------------------------------------------------------+
```

### Sorted Set DocValues Layout
```
+-----------------------------------------------------------+
| Doc Count (VInt)                                          |
| Global Dictionary Length (VInt)                           |
|   Term 0 (VByte len + UTF-8) ... Term D                   |
| Per-Document Ordinal Lists:                               |
|   Doc 0: Ordinal Count (VInt) | Ord Deltas (VInt...)      |
|   Doc 1 ... Doc N                                         |
+-----------------------------------------------------------+
```

---

## 4. Stored Document Fields (`.cbl_fdx` and `.cbl_fdt`)

Stored fields decouple inverted indexes from document retrieval. Documents are stored in compressed blocks of 64 documents.

### Index File (`.cbl_fdx`)
```
+-----------------------------------------------------------+
| Block Count (VInt)                                        |
| Block 0: Start Doc ID (VInt) | File Byte Offset (Int64)   |
| Block 1 ... Block B                                       |
+-----------------------------------------------------------+
```

### Data File (`.cbl_fdt`)
```
+-----------------------------------------------------------+
| Block 0 Payload Length (VInt)                             |
| Block 0 Compressed UTF-8 JSON Documents                   |
| Block 1 ... Block B                                       |
+-----------------------------------------------------------+
```

---

## 5. HNSW Vector Index (`.cbl_vec`)

Stores the multi-layer Hierarchical Navigable Small World graph for approximate nearest neighbor retrieval.

```
+-----------------------------------------------------------+
| Magic Bytes: 0x43425643 ('CBVC') (Uint32)                 |
| Format Version: 1 (Uint32)                                |
| Vector Dimension (VInt)                                   |
| Distance Metric Code: L2 (1) | Cosine (2) | Dot (3) (Byte)|
| Max Layer Level (VInt)                                    |
| Entry Point Document ID (VInt)                            |
+-----------------------------------------------------------+
| Vector Data Buffer:                                       |
|   Doc 0: Float32[dimension]                               |
|   Doc 1 ... Doc N                                         |
+-----------------------------------------------------------+
| Graph Adjacency Topology:                                 |
|   Layer 0 .. Layer Max:                                   |
|     Node Count (VInt)                                     |
|     Node: DocId (VInt) | Neighbor Count (VInt)            |
|           Neighbor 0 (VInt) ... Neighbor M (VInt)         |
+-----------------------------------------------------------+
```

---

## 6. Deletion Vectors (`.cbl_del`)

RoaringBitmap representation of soft-deleted internal document IDs.

```
+-----------------------------------------------------------+
| Deletion Generation (VInt)                                |
| Serialized Bitmap Byte Length (VInt)                      |
| RoaringBitmap Payload:                                    |
|   Chunk Count (Uint32)                                    |
|   Chunk Descriptors: [ChunkKey: Uint16 | Size: Uint16]    |
|   Containers: ArrayContainer / BitmapContainer / Run      |
+-----------------------------------------------------------+
```

---

## 7. Write-Ahead Log (`corbel.wal`)

Crash resilience log recording uncommitted document insertions, updates, and deletes.

```
+-----------------------------------------------------------+
| Header: Magic 0x57414C31 ('WAL1') | Version 1             |
+-----------------------------------------------------------+
| Frame 0:                                                  |
|   Frame Length (Int32, 4 bytes)                           |
|   Log Sequence Number (Int64, 8 bytes)                    |
|   Operation Code: Insert (1) | Delete (3) (Byte, 1 byte)  |
|   Payload: Document ID + JSON UTF-8 payload               |
|   Frame Checksum: CRC32C over LSN + OpCode + Payload      |
+-----------------------------------------------------------+
| Frame 1 ... Frame N                                       |
+-----------------------------------------------------------+
```
